# T9 Time — Pebble app store listing

## Name

T9 Time

## Description

T9 Time turns each minute into a tiny predictive-text moment. The numeric clock updates immediately, then the hour and minute type themselves while the matching T9 keys light up. When two words share a key sequence, the face briefly shows another candidate before settling on the time. Choose the Original face, a Nokia 3310 treatment, or a Motorola RAZR V3 treatment with sweeping keypad lines. Show or hide the battery icon, select 12-hour or 24-hour time, choose O'CLOCK or OH ZERO at :00, and use model colors or your own background and text colors. Made for Pebble Time 2.

## Initial release notes

First release: animated T9 time, 12-hour and 24-hour display, and independent background and text colors.

## 0.2.0 release notes

Adds selectable 3310 and RAZR V3-inspired displays and keypads, model color palettes, and an optional watch-battery icon. Existing T9 typing, 12/24-hour time, and custom colors remain available.

## 0.2.1 release notes

Aligns the 3310 clock colon with the digits, removes the connection bars, and gives the 3310 keypad individually shaped oval keys. Restores the original spacing between the T9 digit line and keypad while keeping the optional watch-battery icon.

## 0.2.2 release notes

Adds an O'CLOCK or OH ZERO choice for minute 00. Gives two-line RAZR minutes more room and clears the T9 sequence from the lower frame and keypad.

## 0.2.3 release notes
